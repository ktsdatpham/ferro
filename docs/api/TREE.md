# Ferro API map

Generated by `scripts/api_tree.py` from the sources — do not edit by
hand; run the script and commit. Like the Revit API namespace tree:
crate → module → public items. Layers inside `ferro-core` depend
downward only: `math → geom → topo → algo → model → ops` (D-19).

Methods are listed under their type as `Type::method`.

### `ferro_tools::parameter`

`set_parameter` values at the edge (ADR 0004 §2): agents may give quantities with units, which are converted here to storage units (`ParamValue::Quantity`, SI; mm for length, rad for angle).

- fn `param_value` — Convert an agent `set_parameter` value to the kernel's `ParamValue` JSON.
