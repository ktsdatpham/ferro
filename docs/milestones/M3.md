# Milestone 3: Revit link and IFC

Goal: a design started in Ferro reaches Revit as native walls, floors, doors
and windows, changes made in Revit come back to Ferro, and the model exports
to IFC4.

## Verified

- Unit tests: plan ordering, feet, signatures and deletes; import create /
  update / delete; plan → import round trip; default level mapping; IFC
  structure and determinism; T-joins.
- IFC files pass IfcOpenShell schema validation (0 issues) and every product
  builds geometry.
- A script speaking the add-in's protocol ran against the live app: a full
  plan, an empty second plan, an unchanged push (no step), and a push with a
  new wall arriving as a proposal.

## Notes

- The add-in has not been run inside Revit by CI; please report the first run.
- Floors are recreated on change in Revit (their sketches are not edited).
- Revit 2024 and older need a .NET Framework 4.8 target (later).
