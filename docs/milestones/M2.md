# Milestone 2: BIM elements and live AI

Goal: a designer draws real walls, floors, doors and windows with types and
materials, and an AI agent (an MCP client or the built-in chat) edits the model
that is open in the app, as a proposal the designer accepts or rejects.

Per the import/export roadmap (D-75) the Revit link is milestone 3.

## Done means

- `cargo test --workspace`, clippy, fmt, WASM build all green.
- An agent builds a house through ferro-mcp while the app is open; the change
  arrives as one proposal; Accept makes it one undo step attributed to the agent.
- The same house drawn by hand with the Wall, Door, Window and Floor tools.

## Notes from the M2 build

- Wall solids are single closed bodies; layers are data (for quantities and
  Revit / IFC export) and are not yet drawn as separate solids.
- Joins are inferred from coincident end points (exactly two straight walls).
  A wall that ends in the middle of another wall overlaps it for now.
- Push/pull never changes thickness; that is the type's job (change the type).
- The chat key is stored in plain text in `~/.ferro/settings.json`.
