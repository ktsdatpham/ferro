# Milestone 1: Kernel to spec + first drawable app

Goal: the v0.1 prototype is rebuilt on the Foundation Spec, and a designer can
open a window, draw rectangles, push-pull them, orbit, undo, save a `.fro`, and an
AI agent can do the same through MCP.

Each step is one small PR, in this order. A step may start only when the previous
one is merged (they build on each other).

## Done means

- `cargo test --workspace`, clippy, fmt, WASM build all green.
- A recorded demo: draw → push-pull → undo → save → reopen → same model; the
  same model built by an MCP agent.
- The "Status of the current code" list in the Foundation README lists only milestone 2 items.

## Notes from the M1 build

- Push / pull on a closed solid supports the two common cases: all neighbouring
  faces perpendicular (stretch, e.g. boxes) and no perpendicular neighbour
  (prism). Mixed cases return `ferro.algo.unsupported` (milestone 2).
- Cylinder faces are stored as faceted planar faces carrying the exact
  `Cylinder` surface and a smooth group; single exact curved faces with arc
  edges come with milestone 2.
- AI changes from MCP are applied directly (with undo and journal). Proposal
  mode (D-26) needs Ferro Link and lands in milestone 2.
- The app is verified headless (Xvfb + software Vulkan) by driving the mouse
  and keyboard; see the screenshot in the README.
