# Milestone 5: Foundation 2

Goal: the data model and geometry foundation from ADR 0004, before more
features are built. No releases; each step merges to `main` with files
from earlier milestones still opening.

| M5-3 | **Quantities**: spec table, `ParamValue::Quantity`, parameter definitions with `Uid`, Revit / IFC mapping | §2 | |
| M5-4 | **Material assets**: appearance (OpenPBR subset), physical, thermal, environmental, cost; U-value, mass and carbon per type | §3 | |
