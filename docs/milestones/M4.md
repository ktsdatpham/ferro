# Milestone 4: SketchUp parity

Goal: someone who models in SketchUp can model in Ferro without missing the
everyday tools. No releases during this milestone; each step merges to `main`.

Order is by how often the tool is used in a SketchUp session.

| # | Step | SketchUp | Status |
|---|---|---|---|
| M4-1 | **Imprint**: lines, rectangles, polygons and circles drawn on a face split it (planar arrangement), so the new face can be pushed / pulled in or out | sticky geometry on faces | done |
| M4-2 | **Line tool** (L): chains of edges; a line across a face splits it | Line | done |
| M4-3 | **Circle (C), Arc (A), regular Polygon** on any face plane or the ground | Circle, Arc, Polygon | done |
| M4-4 | Shapes on **any face plane** (vertical walls, sloped roofs), not only horizontal | — | done |
| M4-5 | **Push/Pull** general cases: mixed neighbours, faces with holes, push through to make a hole, repeat last distance (double-click) | Push/Pull | done |
| M4-6 | **Offset** (F) | Offset | done |
| M4-7 | **Rotate** (Q) and **Scale** (S) tools, with typed values | Rotate, Scale | done |
| M4-8 | **Edit a Form** (double-click, like a SketchUp group): select faces / edges / vertices; Move stretches them; Delete erases edges and heals faces | group editing, Move on faces | done |
| M4-9 | **Selection**: window (left→right) and crossing (right→left) drag; Ctrl+A; select all of a kind | Select | done |
| M4-10 | **Camera**: standard views (Top, Front, Right, Back, Left, Iso), parallel projection, zoom window, Shift+Z extents | Camera | partial: views, parallel projection; zoom window and Shift+Z to do |
| M4-11 | **Inference**: Shift locks the inferred direction, arrow keys lock axes, parallel / perpendicular to an edge, inference from a point | Inference | done: axes, parallel / perpendicular to the last hovered edge; Shift and arrow keys lock |
| M4-12 | **Copy / paste** (Ctrl+C / V), **arrays** after Move-copy (`5x`, `/5`) | arrays | done |
| M4-13 | **Paint bucket** (B): materials on Forms and faces; material browser | Paint Bucket | partial: whole Forms; per-face paint to do |
| M4-14 | **Styles**: X-ray, wireframe, hidden line, shaded; section plane | Styles, Section | partial: X-ray, wireframe; hidden line and section plane to do |
| M4-15 | **Tape measure** (T) guides and **Dimensions** | Tape Measure, Dimension | partial: Tape measures distances; guides and dimensions to do |
| M4-16 | **Tags** visibility panel (D-74), hide / unhide | Tags | done (hiding is view state, not saved) |
| M4-17 | **Components**: instances sharing one definition (with families) | Components | later |
| M4-18 | Shadows and sun (moves with the Render workspace) | Shadows | later |

Shortcuts follow SketchUp's defaults. BIM tools move to keys SketchUp does not
use: Wall W, Floor U, Door D, Window N.
