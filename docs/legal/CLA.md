## How to sign

Add this line to the description of your first pull request:

```
I have read the Ferro CLA (docs/legal/CLA.md) and I agree to it. — <your GitHub login>
```

CI (`cla` job) checks for it. For AI agents opening pull requests on a user's
behalf, the user signs: the line names the human GitHub account responsible.
